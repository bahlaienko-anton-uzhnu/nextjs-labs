# 📚 Бібліотека — Next.js Library System

Система управління бібліотекою, створена на Next.js 15 + MongoDB.

## 🚀 Можливості

- Реєстрація та авторизація користувачів
- Ролі користувачів (admin / user)
- CRUD для книг
- CRUD для замовлень
- Онлайн бронювання книг
- Dashboard адміністратора
- Toast повідомлення
- SEO оптимізація
- Sitemap та robots.txt
- Responsive UI
- Захист маршрутів через middleware

---

## 🛠️ Технології

- Next.js 15
- React
- Tailwind CSS
- MongoDB + Mongoose
- NextAuth.js
- React Hook Form
- Zod
- Sonner
